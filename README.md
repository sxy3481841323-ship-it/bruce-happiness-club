# 布鲁斯日常 · 幸福指数俱乐部 (`Bruce Happiness Club`)

一款明快年轻、手绘插画感的全画幅陪伴网页游戏：玩家可选年轻潮酷的男主 **Alex** 或女主 **Meya**，在带有现代古典留白比例的独栋别墅小院、精品绿道街区与远方世界地标中，陪伴奶油长毛腊肠犬 **布鲁斯**。

## 核心规则
1. **初始幸福指数 = 100**（既是全服排行榜分数，也是冷战期买零食哄狗的唯一货币）。
2. **高于或等于 80 分**：可游玩「独栋小院（5 个互动）」与「精品街区（5 个互动）」共 **10 个高精动画交互小游戏**。画面内道具与招牌为英文，引导与旁白为中文，地图插画绝无地名文字。
3. **低于 80 分**：进入冷战锁定状态，不能通过陪玩加分，只能花费幸福指数在 **8 档极简食物（`BISCUIT` 5 分 → `WAGYU` 68 分）** 中概率拉回正常范围。
4. **低于 5 分（买不起最便宜饼干）**：解锁小视频急救放映室（预留 `assets/video/rescue.mp4`，未放入前自带 5 秒倒计时占位），看完精准拉回 **80 分**。
5. **含义 A 高位交换**：触发幸运事件时，只从排在当前玩家前面的高分玩家中抽取，且**第 1 名被抽中概率最低，名次越往下被抽中概率越高**；互换后立即写入顶部**全服吃瓜滚动公告**。

## 本地运行与联调
```bash
python3 scripts/dev_server.py --port 8778
```
打开 `http://127.0.0.1:8778` 即可完整试玩。

## 放置复活小视频
将制作好的 MP4 命名为 `rescue.mp4` 放入 `assets/video/rescue.mp4` 即可自动替换占位放映位。
